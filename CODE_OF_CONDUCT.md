# Contributor Code of Conduct

Be respectful, professional and constructive in project discussions. Technical disagreements should be addressed with evidence and clear explanations. Harassment, threats, discriminatory conduct, disclosure of another person's private information and publication of production secrets are not accepted.

Please report concerns privately through GitHub's repository reporting mechanisms when available. Maintainers may remove inappropriate content or restrict participation. This document is a lightweight project code of conduct, not a claim of affiliation with any external organization.
